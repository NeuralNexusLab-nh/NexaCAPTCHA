FEATURES

Why use NexaCAPTCHA?

Readable intervals help people, while changing contours, decoy strokes, and slow color exchange make direct frame stacking unreliable.

Readable in motion

Each character gets a short clear interval, but no frame presents all four as one clean OCR target.

Stable core, changing contours

The main skeleton stays readable while light outlines and brightness details change between frames.

Independent smooth movement

Every character moves, rotates, and scales smoothly without instant jumps.

Moving decoy strokes

Small nearby decorations remain harmless in one frame but create misleading contours when frames are stacked.

Slow color exchange

Character colors transition gradually, preventing a fixed-color tracking shortcut while remaining easy to follow.

Higher solving cost

Bots must align motion, reject decoys, and recover stable skeletons instead of reading or stacking one image.

SETUP

Add NexaCAPTCHA to your site

Copy these two pieces. No frontend framework is required.

1

Paste this into your HTML

The Script loads NexaCAPTCHA. The Div chooses where it appears.

HTML · page markup
<script src="https://nexacaptcha.zone.id/captcha.js" defer></script>

<div class="nexa-captcha" data-callback="onNexaComplete"></div>
2

Send the result with your form

Put this in your frontend JavaScript. Replace yourSubmitFunction with your existing submit function.

JavaScript · frontend
function onNexaComplete(result) {
  if (!result.success) return;

  yourSubmitFunction({
    verificationId: result.verificationId,
    responseToken: result.responseToken
  });
}

Two values come back

verificationId
The ID of the completed CAPTCHA.
responseToken
Proof that it was completed. It works once.

BACKEND VERIFICATION

Check it on your server

Before accepting the form, signup, or login, send both values to NexaCAPTCHA.

POST/api/siteverify

Request

{
  "verificationId": "<verificationId>",
  "responseToken": "<responseToken>"
}

Response · success

{
  "success": true,
  "verifiedAt": "2026-08-07T12:30:00.000Z"
}

Response · failure

{
  "success": false,
  "errorCode": "invalid-or-expired-verification"
}
Node.js · backend
const response = await fetch(
  "https://nexacaptcha.zone.id/api/siteverify",
  {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      verificationId,
      responseToken
    })
  }
);

const result = await response.json();
if (!result.success) {
  return res.status(403).send("Verification failed");
}

Continue only when the response says success: true. A responseToken works once and expires after five minutes.
