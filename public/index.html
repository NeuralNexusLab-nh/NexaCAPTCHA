INTEGRATION

Add NexaCAPTCHA

Add one script and one mount point. NexaCAPTCHA renders the complete interface.

1

Embed the widget

Place this where the verification interface should appear.

HTML 
<script
  src="https://nexacaptcha.zone.id/v1/captcha.js"
  defer
></script>

<div
  class="nexa-captcha"
  data-callback="onNexaComplete"
></div>
2

Receive the output

The callback receives JSON after the user completes the challenge.

JavaScript 
function onNexaComplete(result) {
  if (!result.success) return;

  console.log(result.challengeId);
  console.log(result.responseToken);
}

Input

The user enters the four characters shown through the moving reveal.

{ "answer": "NEXA" }

Output

A completed challenge returns its public ID and one-time response token.

{ "success": true, "challengeId": "chl_…", "responseToken": "…" }

SERVER VERIFICATION

Verify from your backend

Send both values to NexaCAPTCHA before accepting the protected action.

Node.js 
const response = await fetch(
  "https://nexacaptcha.zone.id/api/v1/siteverify",
  {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      challengeId: req.body.challengeId,
      responseToken: req.body.responseToken
    })
  }
);

const verification = await response.json();

if (!verification.success) {
  return res.status(403).json({
    error: "CAPTCHA verification failed"
  });
}

Request input

challengeId
Public challenge identifier.
responseToken
32-character, short-lived, one-time token.

Response output

success
True only when the token is valid and consumed.
verifiedAt
UTC verification timestamp on success.

Backend verification is required

Never trust frontend completion alone. Always verify the response token from your backend.
