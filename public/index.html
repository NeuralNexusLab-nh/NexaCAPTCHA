FEATURES

Why NexaCAPTCHA?

A normal text CAPTCHA can be read from one picture. NexaCAPTCHA spreads the useful parts across an animation.

Four independent movements

Each character changes direction, speed, rotation, and shape on its own 1.25–5 second cycle.

Only fragments stay visible

The window changes speed and sometimes moves backward. A complete character appears only briefly.

Simple to add

Load one script, add one element, then verify two values from your backend.

SETUP

Add it in two small steps

The CAPTCHA handles its own display and answer checking.

1

Load the widget

Add this script and place the CAPTCHA where you want it.

HTML · page markup
<script src="https://nexacaptcha.zone.id/v1/captcha.js" defer></script>

<div class="nexa-captcha" data-callback="onNexaComplete"></div>
2

Submit with your own function

Put this in your frontend JavaScript. Replace yourSubmitFunction with the function that submits your form to your backend.

JavaScript · frontend
function onNexaComplete(result) {
  if (!result.success) return;

  yourSubmitFunction({
    verificationId: result.verificationId,
    responseToken: result.responseToken
  });
}

The two values you need

verificationId
Identifies which completed CAPTCHA is being checked.
responseToken
A 32-character, one-time proof returned after the correct answer.

BACKEND VERIFICATION

Confirm the result

Your backend sends the two values to one endpoint before accepting the form, signup, or login.

The /v1/ paths are stable and will not be renamed.

POST/api/v1/siteverify

Request

{
  "verificationId": "<verificationId>",
  "responseToken": "<responseToken>"
}

Response · success

{
  "success": true,
  "verifiedAt": "2026-08-07T12:30:00.000Z"
}

Response · failure

{
  "success": false,
  "errorCode": "invalid-or-expired-verification"
}
Node.js · backend
const response = await fetch(
  "https://nexacaptcha.zone.id/api/v1/siteverify",
  {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      verificationId,
      responseToken
    })
  }
);

const result = await response.json();
if (!result.success) {
  return res.status(403).send("Verification failed");
}

Only accept the protected action when siteverify returns success: true. Each responseToken works once and expires after five minutes.
