WHY IT IS DIFFERENT

Recognition requires time, not one screenshot.

Traditional image CAPTCHAs expose the complete text at once. NexaCAPTCHA distributes useful visual context across a changing sequence.

Static CAPTCHA

Why automated solving costs more

A model cannot rely on one clean input. It needs a temporal pipeline and more inference work per verification. NexaCAPTCHA is not “AI-proof”; it is designed to make reliable automation less direct and more expensive.

INTEGRATION

Add NexaCAPTCHA

The loader creates the complete isolated interface inside your mount point.

1

Embed the widget

Place this markup where verification should appear.

HTML
<script
  src="https://nexacaptcha.zone.id/v1/captcha.js"
  defer
></script>

<div
  class="nexa-captcha"
  data-callback="onNexaComplete"
></div>
2

Receive browser output

The callback returns a verification ID and one-time token after success.

JavaScript
function onNexaComplete(result) {
  if (!result.success) return;

  console.log(result.verificationId);
  console.log(result.responseToken);
}

Browser output

{
  "success": true,
  "verificationId": "ver_G5uQkATY0vYfXxWSMEuT6w",
  "responseToken": "GD8dR4qbKj7s0LmPWz2YxT5eU9nAcFhV"
}

Field meaning

success
True only after the text was entered correctly.
verificationId
Public identifier passed to your backend.
responseToken
32-character token that expires after five minutes and works once.

All endpoints use JSON except the animation response. No site key or authorization header is required.

Node.js verification example

Call the public confirmation endpoint before accepting signup, login, or form submission.

Node.js
const response = await fetch(
  "https://nexacaptcha.zone.id/api/v1/siteverify",
  {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      verificationId: req.body.verificationId,
      responseToken: req.body.responseToken
    })
  }
);

const verification = await response.json();

if (!verification.success) {
  return res.status(403).json({
    error: "CAPTCHA verification failed"
  });
}

Backend confirmation is required

Never trust browser completion alone. Accept the protected action only after siteverify returns success.
